# Calibration Examples

Manuel islem screenshot'larini ve mini bilgileri buraya ekle.

Onerilen duzen:

```text
calibration_examples/
  2026-03-31_long.md
  2026-03-31_long.png
  2026-04-20_short.md
  2026-04-20_short.png
  screenshots/
```

Her ornek icin `example_template.md` dosyasini kopyalayip tarih/yon ile yeniden adlandirabilirsin.

Screenshot icin ideal gorunum:

- NAS100 5m chart
- Volume Profile gorunur
- VAH / VAL cizgileri gorunur
- Sweep, CISD ve FVG/IFVG bolgesi gorunur
- Mum saatleri New York timezone
